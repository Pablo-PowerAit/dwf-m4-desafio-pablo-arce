# Desafío Módulo 4

Portfolio web responsive desarrollado con HTML, CSS y JavaScript.

## Funcionalidades

- Diseño responsive
- Componentes reutilizables
- Navegación entre páginas
- Portfolio y servicios
- Formulario de contacto con envío mediante API
- Manipulación del DOM con JavaScript
